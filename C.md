# C

## Scanf

**铁律 1**

> **格式串里：空格 / \t / \n**

作用完全一样：

👉*持续吃掉所有空白符（空格、回车、制表），直到遇见「非空白」停止*

**铁律** 2

> **`%d` 自带前置消空白**

👉不管前面有多少回车、空格，`%d` 自动跳过，直接找数字。



## 不同数据类型的输入输出格式

| 数据类型       | 含义         | printf输出格式 | scanf输入格式 |
| -------------- | ------------ | -------------- | ------------- |
| char           | 字符         | %c             | %c            |
| unsigned char  | 无符号字符   | %c             | %c            |
| short          | 短整型       | %hd            | %hd           |
| unsigned short | 无符号短整型 | %hu            | %hu           |
| int            | 整型         | %d             | %d            |
| unsigned int   | 无符号整型   | %u             | %u            |
| long           | 长整型       | %ld            | %ld           |
| long long      | 超长整型     | %lld           | %lld          |
| unsigned long  | 无符号长整型 | %lu            | %lu           |
| float          | 单精度浮点   | %f             | %f            |
| double         | 双精度浮点   | %f             | %lf           |
| char[]         | 字符串       | %s             | %s            |

## 运算符优先级

| 优先级 | 运算符           | 结合性                    |      |
| ------ | ---------------- | ------------------------- | ---- |
| 1      | ()               | 从左到右                  |      |
| 2      | !  +  -  ++  --  | 从右到左（单目的 + 和 -） |      |
| 3      | * / %            | 从左到右                  |      |
| 4      | + -              | 从左到右                  |      |
| 5      | < <= > >=        | 从左到右                  |      |
| 6      | == !=            | 从左到右                  |      |
| 7      | &&               | 从左到右                  |      |
| 8      | \|\|             | 从左到右                  | `    |
| 9      | = += -= *= /= %= | 从右到左                  |      |

**条件运算符**（自右向左）

条件 ? 表达式1 : 表达式2

- 条件为真 → 执行 / 取 `表达式1` 的值

- 条件为假 → 执行 / 取 `表达式2` 的值

等价于
if (count > 20){

​	count = count - 10;

} 

else {

​	count = count + 10; 

}



**逗号运算符**（自左向右）

1. *结果取值*：整个逗号表达式的结果，等于**最右边表达式的值**

1. *优先级*：所有运算符中**最低**，低于赋值运算符
